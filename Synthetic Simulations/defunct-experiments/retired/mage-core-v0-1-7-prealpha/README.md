## Technical summary

The archived design proposes:

- A reusable core of versioned schemas, contracts, status vocabulary, and bounded deterministic tools.
- Small project-local descriptors that pin a core version rather than copying a silently diverging core into each attached project.
- Separation of human purpose, evidence, model-assisted reasoning, capabilities, deterministic enforcement, and audit/recovery.
- An advisory model role; consequential actions require separate permission, gates, and appropriate independent recovery.
- A staged, source-protective mining procedure: preflight → physical inventory → classification → bounded extraction → candidate mining → comparison → explicit admission review.
- Explicit non-claims concerning identity authentication, unconstrained agency, hypervisor enforcement, and complete recovery of historical system specifications.

The archive's own README reports work on attachment, inventory reconciliation, and metadata audits. Those claims were **not replayed or independently validated for this publication**.
