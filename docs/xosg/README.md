## Naked Shell and NLP Development Suite

[Naked Shell](../../Naked%20Shell/README.md) now points to the
[NLP Development Suite](../../nlp-development-suite/README.md) as a separate,
candidate source of bounded, non-executing natural-language interpretation
capabilities. The NLP suite's source-preserving candidates, controlled grammar,
and authority-free interpretation envelope are relevant research references for
future shell construction.

**Boundary:** this is a documentation relationship only. Neither a
Naked Shell parser/adapter nor an execution integration has been implemented
or admitted by linking the projects. Proposed shell effects still require
separately specified source, authority, validation, and recovery contracts.

The family moved from OpenSurface to this public repository under explicit user approval on 2026-11-05. All 100 source-tree files are accounted for in the [migration manifest](MIGRATION_MANIFEST.json). See the [migration record](MIGRATION.md) and [validation summary](MIGRATION_VALIDATION.md) for source identities, documentation changes, and proof limits.

This is a separate family from [xOSG-0](../../syn-xOSG-0/README.md). Co-location does not integrate the projects or establish shared runtime, authority, semantics, or compatibility. DWSK supplies storage mechanics; no conversation logger or automatic agent memory service is included.

Original notices and the [MIT License](LICENSE) continue. Omitted third-party payloads remain omitted; their receipts do not license or redistribute them. Public visibility does not promote identities, failed experiments, or source checks into production acceptance.
