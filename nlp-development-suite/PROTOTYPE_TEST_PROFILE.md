# Prototype test profile

The public prototype deliberately excludes dictionary databases and generated lexical shards. Its required checks cover repository sanitization, Lexicon Core, the generic Offline Interpreter, controlled grammar, command aliases, data-free read-only file commands, and JavaScript syntax.

WordNet lookup, relation lookup, Atlas runtime-data loading, historical reconstruction outputs, and full production evidence checks are data-dependent and are not represented as passing in this profile. Run them only in a separately controlled environment with exact source versions and licenses.
