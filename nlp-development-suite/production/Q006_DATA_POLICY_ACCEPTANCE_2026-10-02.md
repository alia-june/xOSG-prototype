# Q-006 data-policy acceptance

## Source

On 2026-10-02, the user explicitly accepted the proposed Q-006 decision after
its licensing, privacy, retention, and redistribution limits were stated.

## Accepted canon

The release may include only the packaged OEWN 2025 candidate data, subject to
preservation and verification of its applicable license and attribution.
Omitted external corpora must not be bundled or redistributed.

Runtime operation is offline: no telemetry, analytics, network transmission,
or background collection. The interpreter does not automatically retain
input. Only explicit user-controlled outputs, redirection, or diagnostic
artifacts may persist.

User acceptance of this policy does not substitute for a license-compliance
review of the exact release candidate.

## Scope

- packaged lexical candidate data;
- omitted external corpora;
- runtime telemetry and network transmission;
- automatic versus user-controlled data retention;
- release-candidate license and attribution checks.

## Locked terms

- `packaged OEWN 2025 candidate data only`;
- `license and attribution must be preserved and verified`;
- `no omitted-corpus redistribution`;
- `no telemetry, analytics, or background collection`;
- `no automatic input retention`.

## Not established by this acceptance

- a legal conclusion that every release artifact is compliant;
- permission to add or redistribute an omitted corpus;
- permission to transmit user input or derived output;
- automatic retention, profiling, or analytics authority;
- production readiness or deployment authority.

## Version and migration

- Decision version: `Q-006/1`.
- Superseded values: none; the prior state was `UNKNOWN` with a generated,
  unaccepted data proposal.
- Migration: any new data source, persistence behavior, telemetry, or network
  transfer requires a separate inventory, license/privacy assessment, tests,
  and explicit acceptance.
- Unresolved conflict: legal/license compliance of the exact release candidate
  must still be verified before distribution.
