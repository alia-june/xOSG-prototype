# Internal test candidate known limitations

- Unpublished internal testbed only; production-ready is false.
- No publication, redistribution, deployment, service, or receiver acceptance.
- No operation-execution interface and no authority effect.
- No runtime dependencies or bundled lexical datasets.
- Optional historical-suite adapters are absent from the wheel.
- No graphical interface is included.
- Windows is the validated host family; basic CLI probes passed CPython
  3.11–3.14, with Python 3.11 canonical for construction.
- Performance thresholds are host-specific testbed criteria, not service-level
  objectives.
- Executable third-party providers remain excluded.
- First-party distribution terms and third-party redistribution obligations
  must be resolved before any future publication.
